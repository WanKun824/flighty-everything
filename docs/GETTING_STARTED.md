# 开始使用

公开仓库的 `main` 保留最新源码，当前没有安装包、截图/GIF 图册或旧版本下载。

```sh
git clone https://github.com/WanKun824/flighty-everything.git
cd flighty-everything
npm ci
npm run dev
```

需要 Node.js 22.13+、npm 和 Git。Windows 可用 `npm.cmd`。不需要登录 GitHub 即可查看或克隆公开源码。
