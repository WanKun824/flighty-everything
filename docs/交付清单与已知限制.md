# 当前源码范围与已知限制

## 保留

- 最新主应用、平台桥接、iOS/Android 工程、依赖锁、测试、数据库迁移和开发文档。
- 应用必需的品牌图标、模型、纹理、机场数据、Gradle wrapper。
- 新环境的虚构演示行程和已有存储保护逻辑。

## 不再保留

- 旧发布、旧版本标签、过时打包/演示分支，以及旧交付验证报告和清单。
- 运行截图、拼版、GIF、录屏、对应逐图说明及媒体清单。
- IPA、APK、AAB、模拟器应用压缩包、Web 构建交付包、源码交付 ZIP 等生成产物。
- 公开仓库的历史打包/截图工作流运行和可下载 artifacts。

当前唯一维护入口是 `main`。私有镜像仓库不在本次清理范围；其内容和下载资产不代表本公开仓库的当前交付。未强制重写 Git 提交历史。

## 尚未解决的问题

- 项目仍为 React + Capacitor 混合应用，不是全量 SwiftUI。
- 旧 CSS 覆盖、字号及约 420 个历史调色板值尚未完全收敛；浅色旅迹对比度、编辑留白、旧引导与状态栏等问题没有因删除图片而解决。
- Lint 已知为 9 errors / 9 warnings；没有禁用规则来伪造通过。
- 构建有大 chunk 提示。依赖安装此前报告 36 项漏洞，包含 high/critical；未进行破坏性强制升级，计数也不是完整安全审计。
- 地图、天气、航班和列车查询依赖第三方网络、token、覆盖和限流；计划、手工记录与实时核验必须区分。
- 同行仅为本地演示；个人行程、资料和草稿不自动云备份。原生社区和 Web D1 社区存在不同的数据路径。
- 尚无完整实体设备、所有 Dynamic Type / VoiceOver、后台定位及业务提交验收。
- 素材许可待核对；完整性检查、编译成功和源码公开均不等于安全认证或苹果签名。

删除旧文件不等于功能问题已经修复。后续验证以当前实际执行结果为准，不再引用被删除的媒体或旧安装包作为证据。
