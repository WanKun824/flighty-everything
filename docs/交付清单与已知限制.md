1. **完整源码 ZIP**：Web/原生共享界面、后端与数据库迁移、iOS/Android 工程、依赖锁、四种交通模型、机场目录、测试、CI、中文文档、历史与当前截图。内置逐文件 SHA-256 清单，外附 ZIP 校验和。

3. **Web 构建包**：Web 生产资源及 Capacitor Web 资源，不能当作 IPA/APK。
4. **iOS 设备 IPA**：真实 Xcode 构建的 arm64 未签名包；内部 `Info.plist` 和 `public/build-info.json` 标识版本与来源。
5. **页面图册**：iOS 浅色/深色分别记录结果，不将 `captured` 等同于视觉/功能合格。

不包含 `.git` 历史、依赖目录、用户数据、线上数据库、私有配置、开发者证书、描述文件、账号口令或 GitHub 令牌。素材许可并不因源码可下载而自动授予。

## 3. 仍需处理的问题

### 样式与自动检查

- 主要界面使用共享语义令牌与 SheetHeader，但旧 CSS 仍有多层覆盖、历史命名空间和约 420 个遗留调色板值。不能把集中到一个文件等同于全部语义化收敛。
- 已知 `npm run lint` 仍有 **9 errors / 9 warnings**，涉及旧 effect 状态同步/依赖、render ref 和 Date.now 规则；没有关闭规则来伪造通过。CI 中任何 lint 失败都应按真实失败解释。
- 字号下限及核心文字色对比度有回归检查，但不代表所有遗留组件、地图标注、动态字体和点击区域均已完全验收。
- **本轮真实 iOS 图册发现浅色最小旅迹数字对比度不足、旅程编辑留白、旧同行引导文案/关闭样式和浅色状态栏对比度等未关闭问题。** 具体截图与检查见 [视觉备注](runtime-20261018/VISUAL_NOTES.md)；本轮是带已知限制的预览交付，不是视觉验收全部通过。
- 构建仍提示部分 JS chunk 超过 500 kB，移动端实际内存、温度、帧率需设备测试。
- 本次依赖安装曾报告 36 项安全问题（含 high/critical），未进行可能破坏兼容性的强制升级；该计数不等于实时完整安全审计。

### 数据与功能

- ADSBDB 核验航线并不保证具体日期时刻、航班执行、登机口和实时位置都已确认；部分计划由用户输入或距离估算，必须查看实际数据来源。
- Transitous/MOTIS 受地区与运营商覆盖限制，不是全球全量列车或 12306 实时接入。
- OurAirports 是机场地点基础目录，演示运营统计不是实时运营通告。
- 当前同行功能是本地演示；本机行程和资料不自动备份或跨设备同步。
- Web D1 社区与原生本地/示例社区不同。截图不执行发布、点赞、邀请、定位授权或确认删除，不能据此证明这些业务成功。
- 地图、天气和查询受网络、公开 token、区域覆盖与第三方限流影响。图册中地图空白/加载失败必须如实记录。

### 安装、权限与版本

- 未签名 IPA 不能直接安装到标准 iPhone；需要用户自行完成合法适用的签名流程，不是 TestFlight 分发。
- `xcode-27` 是本仓库当前可用环境标签，不代表所有 GitHub 账号均有同样 runner、SDK 或额度。
- 截图来源提交与最终文档提交可能不同；若后者只补文档/图片，须同时列出两者，并核对应用源码树一致，不能混淆版本。
- [MODEL_LICENSES.md](../MODEL_LICENSES.md) 中未全部确认的素材许可，须在商用/再分发前核实。Apple 风格不代表 Apple 官方认证。

## 4. 文件校验

```sh
python scripts/package-source.py --verify /path/to/source.zip
```

`SOURCE-MANIFEST.json` 保存源提交、打包时间、文件列表、大小及 SHA-256；清单本身不自引用。Release 的 `SHA256SUMS.txt` 用于验证下载资产没有损坏，不是苹果代码签名或安全认证。
