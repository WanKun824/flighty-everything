# 测试与量测

## 回归入口

```sh
npm test
npx tsc --noEmit -p tsconfig.json
npx playwright test
npm run lint
```

Node 测试检查数据、几何、时钟、设计令牌与源码契约。浏览器测试在 402 × 874 的浅/深色与 320 × 667 小屏中检查导航、添加草稿、删除确认/撤销、存储保护、统计筛选和布局。

`tests/e2e/navigation-plan.spec.mjs` 复用 32 个页面目标，只验证可达性，不写图片。Playwright 默认关闭 screenshot 和 trace，普通回归不再输出截图/GIF/录屏。浏览器使用隔离配置，不读取日常浏览器数据。

部分外部服务故意离线，能够验证降级状态，不能用来证明实际地图、天气、交通查询或所有原生插件均正确。

## 运动与性能

- 测量载具时使用相同模型、相机缩放、设备像素比和渲染环境，区分冷加载与稳定播放。
- 用页面内 `requestAnimationFrame` 和 `performance.now()` 采样，检查位移、方向、帧间隔和掉帧；不靠截图间隔推断实时帧率。
- 测试播放时钟必须覆盖暂停、后台恢复、模型未准备好、减弱动态效果和选择切换。
- 不把模拟地图时长当成真实速度，不把示意铁路或道路当作核验路线。

## 真实边界

静态测试、浏览器交互、原生编译、真机触摸、系统权限、辅助功能和真实业务提交是不同门槛。当前未全部通过；已有 lint、样式、依赖安全和设备验收待办应继续如实记录。删除旧媒体不改变这些结论。
