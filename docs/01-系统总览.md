# 1 · 系统总览

## 1.1 这个项目是什么

一个旅行社交 App 的可运行原型，四屏：社区、**探索**、私信、我的。核心是探索屏 ——
一个 Mapbox 地球仪，上面有真实坐标的站点、按真实基准生成的行程线，
和一辆沿线跑的 3D 载具。三端（Web / iOS / Android）共用同一套 DOM，只换设计令牌。

产品的主体是探索屏，其余三屏是静态假数据的门面（`posts`、`conversations` 等常量），
没有网络请求，也没有真正的状态机。改功能基本只会碰探索屏。

## 1.2 技术栈与它的坑

| 层 | 用的东西 | 要注意的 |
| --- | --- | --- |
| 框架 | **vinext 1.0.0-beta.2** | 不是 Next.js。Vite 8 + RSC 上实现 App Router 语义 |
| 运行时 | Cloudflare Workers（本地 Wrangler/Miniflare） | 没有 Node API；`worker/index.ts` 是入口 |
| UI | React 19.2.6 + Tailwind 4.2.1 | Tailwind 只提供 reset 和少量工具类，布局几乎全是手写 CSS |
| 地图 | mapbox-gl 3.28.1 | 独立懒加载块，约 485KB gz |
| 3D | three 0.180 + GLTFLoader + DRACOLoader | 独立懒加载块，约 128KB gz |
| 图标 | `sf-symbols-lib` 2.0.1 + `public/material-icons/` | iOS 用 SF Symbols，Android 用 Material |
| 原生壳 | Capacitor 8.5 | 加载线上站点，不是离线包 |
| 语言/工具 | TypeScript 5.9.3、wrangler 4.92.0 | Node ≥ 22.13.0 |

三个容易踩的地方：

- **`next.config.ts` 是空的**（`{}`），`next-env.d.ts` 和 `.next/` 都是脚手架残留。改它不会有任何效果。
- **`db/` 与 `drizzle/` 完全没被引用。** `db/schema.ts` = `export {}`，`drizzle.config.ts` 指向那个空 schema，
  `.openai/hosting.json` 里 `d1` 和 `r2` 都是 `null`。别以为有后端存储。
- **三条既存的类型错误**，非本次引入、未修，`npm run lint` 和 `npm test` 都能通过：
  - `db/index.ts(1,21) TS2307` 找不到 `cloudflare:workers`
  - `worker/index.ts(6,11) TS2304` 找不到 `Fetcher`
  - `worker/index.ts(7,7) TS2552` 找不到 `D1Database`

  都是缺 `@cloudflare/workers-types` 造成的。要修就装那个包，别去改 `worker/index.ts` 的逻辑。

## 1.3 请求怎么走

```
浏览器
  │
  ├─ /_vinext/image?...        → worker/index.ts → handleImageOptimization
  │                              （env.ASSETS.fetch 取原图 → env.IMAGES.input().transform().output()）
  └─ 其它一切                   → vinext/server/app-router-entry
                                  → app/layout.tsx → app/page.tsx（RSC → 客户端 hydrate）
```

`worker/index.ts` 只有 47 行，全部内容就是上面这个分叉。图片优化走 Cloudflare Images 绑定；
本地开发时该绑定不存在，图片直出原图。

`app/page.tsx` 顶部虽然没有 `"use client"`，但它导入的 `routeGeometry.ts`、`Vehicle3D.tsx` 等都有 ——
实际渲染路径是「服务端出壳 → 客户端接管」。`tests/rendered-html.test.mjs` 就是在验服务端那一半
（`<title>`、og 标签、`class="app-shell"`、`社区` 字样都必须出现在 SSR 的 HTML 里）。

## 1.4 构建管线

`vite.config.ts` 只有三个插件，顺序有意义：

```ts
vinext()                              // App Router 语义
sites()                               // ./build/sites-vite-plugin，注入 .openai/hosting.json 的绑定
cloudflare({
  viteEnvironment: { name: "rsc", childEnvironments: ["ssr"] },
  config: localBindingConfig,         // d1 / r2 来自 .openai/hosting.json，当前都是 null
})
```

Wrangler/Miniflare 的本地状态落在项目内的 `.wrangler/`，`.vinext/` 是 vinext 的中间产物。
两个目录都可以整个删掉重建。

产物：`dist/` 约 8MB；首屏 gzip 约 163KB；mapbox-gl 和 three 各自是独立懒加载块
（进探索屏才拉 mapbox，载具第一次要显示才拉 three）。

## 1.6 一条纵向的数据流

改任何东西之前，先在脑子里跑通这一条：

```
initialTripStops（6 个站，含真实坐标）
  │
  ├─ useJourneyPaths(stops, token)          routeGeometry.ts
  │     每段按 mode 决定形状：
  │       car / train → Mapbox Directions driving（7s 超时、3.2 倍合理性闸门，失败退大圆）
  │       flight / ferry → geodesic() 球面 slerp 96 步
  │     → paths: LegPath[]（coordinates / km / cumulativeKm / cumulativeWeb / source）
  │     → timeline: 按巡航速度加权、再按 hours^0.6 压缩
  │
  ├─ useJourneyClock(isPlaying, speed, zoomRateRef)
  │     每帧 progressRef.current += Δt / (329 / (speed × zoomFactor))
  │     每 62ms 把它快照进 progress（给面板文字和进度条）
  │
  └─ MapCanvas 的逐帧 rAF
        locate(timeline, progressRef.current) → { legIndex, legProgress }
        sampleAt(path, legProgress)           → { coordinate, bearing, lineProgress }
        ├─ marker.setLngLat(coordinate)
        ├─ 屏幕航向 = bearing − map.getBearing()，指数低通 HEADING_SMOOTH=5
        │     → 转过 2° 才 setState → Vehicle3D 收到新 heading
        ├─ setPaintProperty("route-trail", "line-gradient", trailGradient(lineProgress))
        └─ follow 时 center 按 .06 插值后 jumpTo
```

三个刻意的分层，动它们之前要想清楚：

- **每帧的量走 ref，低频的量走 state。** 位置、航向、轨迹刻度每帧都变，全部命令式写进 Mapbox；
  只有「换段」「转过 2°」这种事件才推 React。
- **地图实例只创建一次。** 依赖数组是空的（带 `eslint-disable`）。以前依赖里带 `stops`，
  编辑一次行程整张地图就销毁重建，丢相机位置还差点耗尽 WebGL 上下文。
- **所有回调镜像进 `live` ref。** rAF 循环和地图事件读 `live.current`，
  所以换回调不会重建地图和监听器。

## 1.7 本地运行

```bash
npm ci
npm run dev        # http://localhost:3000
```

平台预览：`?platform=web` / `?platform=ios` / `?platform=android`，或「我的 → 设置 → 界面与设备」。

`.env.local`（**不要提交**）：

```dotenv
NEXT_PUBLIC_MAPBOX_TOKEN=你的_Mapbox_public_token
```

不配也能跑 —— `MAPBOX_TOKEN` 有硬编码回退值。但那个 token 是别人的，
上线前必须替换并在 Mapbox 后台限制 URL 与 API 权限。

检查：

```bash
npm run lint       # 0 error，16 条 @next/next/no-img-element warning 是既有的
npm test           # 先跑一次完整生产构建，再执行 tests/*.test.mjs，基线 49/49
npx cap doctor
npx cap sync
```

`npm test` 会先 build，所以不快（分钟级）。改前端逻辑时先跑 `npm run lint`，提交前再跑 `npm test`。
