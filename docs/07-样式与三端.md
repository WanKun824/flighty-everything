## 7.2 三端分支（html[data-platform=…]）

平台由 `platform.ts` 判定并持久化：`?platform=` 查询参数 > localStorage
`manyou:platform-preference`（「我的 → 设置 → 界面与设备」写入）> Capacitor 原生平台 >
Web 默认。`usePlatformMode` 把它写进 `documentElement.dataset.platform`（一处
`react-hooks/set-state-in-effect` 豁免）。测试 `platform.test.mjs` 验「三端参数只接受
受支持平台」与「自动跟随容器、手动覆盖容器」。

| 平台 | 覆盖什么 | 关键差异 |
| --- | --- | --- |
| **web** | 毛玻璃全关（`backdrop-filter: none`）、舞台与外框布局 | 实体卡片 + 低阴影，**不用系统级毛玻璃** |
| **ios** | `--blue: #0a84ff`、圆角更大（32/22/16）、`backdrop-filter: blur(42px) saturate(160%)` 只在浮层（导航、工具栏、控制层），内容卡片保持实体 | Liquid Glass 只属于浮在内容上方的层；`env(safe-area-inset-bottom)` 管底栏 |
| **android** | 整套 M3 令牌：`--blue: #465d91`、`#17305f` 活性色、Roboto/Noto Sans SC、8dp 节奏、大圆角、Material 图标 | tonal surface，active indicator 用 `#d9e2ff` 药丸；窄屏 tabbar 贴边（Android 习惯） |

图标策略：iOS 用 `sf-symbols-lib`（SF Symbols），Android 用 `.material-glyph`
（`mask: url(/material-icons/*.svg)` + `currentColor`，Apache-2.0）。JSX 里两套都有，
平台分支负责隐藏不匹配的那套。`sf-symbols-lib` 2.0.1 把图标组件（`SFAirplane` 等）编译成
内联 SVG —— 探索屏顶栏和播放器全用它，不是字体图标。

## 7.3 三端分支的隐式约束

- **探索屏在窄屏有专属覆盖**（≤900：`globe-bar` 变窄、`journey-panel` 变 sheet、
  `.map-rider` 基准宽 96→76px、`add-place-sheet` 变宽、`--sheet-h` 联动版权条）——
  都在 557–580 行，改探索屏样式时别漏。
- **class 名与 JSX 的对应由测试盯着**：`rendered-html.test.mjs` 会扫 JSX 里的静态字面量
  类名、对 globals.css 的选择器。**类名必须保持静态字符串**（动态拼出来的会被漏检），
  状态一律走 `data-*` 属性（见文档 5 §5.4）。
- `prefers-reduced-motion`（687 行）会把所有动画/过渡压到 .001ms —— 三端通用，别绕过它。
- 行很长是刻意的：一条规则一行，压缩滚读成本。
