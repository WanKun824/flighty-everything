# iOS 外观统一与跟随渲染调整

- 以深色组件为统一基线，浅色只替换表面、文字、分隔线等色彩变量；统一弹层圆角、阴影、输入框、禁用按钮及选中态，移除浅色专属的卡片阴影差异。
- 静态代码排查发现：镜头每次 rAF 都调用地图 `jumpTo`，载具还有独立 rAF 渲染；在高刷新率 iPhone 上会增加整幅地图绘制压力。原生地图还开启了全屏 MSAA，大面积面板同时执行 34px 模糊、饱和度和亮度过滤。
- 原生地图关闭额外 MSAA，镜头更新及载具绘制最多每秒 60 次，并跳过隐藏页面渲染。行程进度仍按真实经过时间计算，不降低播放速度，不修改缩放、朝向和载具材质。
- 跟随期间面板使用 16px 玻璃模糊，保留半透明背景与原生 Dock 玻璃，去掉该状态下的饱和度/亮度额外过滤；减少透明度辅助功能继续生效。

本次根据代码定位渲染负担，没有在手机上测量帧率；不能保证所有机型稳定 60 FPS。按要求只编译新 IPA，不运行测试或截图工作流。已有运行图册属于此前版本，不代表本次修改后画面。
