# 运行截图的可见问题与覆盖限制

本次任务是 GitHub Mac/Xcode 编译、实际页面截图及说明更新，不是 UI 修复发布。原图保留采集时的页面与问题，没有修图或使用设计参考图替代。编译成功、页面被采集与视觉验收通过是不同结论。

## 查看方法

本册提供 32 张浅色原始 PNG；深色采集未完成，按用户要求使用已有图片并停止补拍。检查使用缩略图拼版逐张查看，再放大有疑问的原图。拼版只供检查，不作为交付截图。页面说明中的标题列表来自页面 DOM，可能包含被当前面板遮住的底层标题；不能据此认定这些标题都显示在屏幕上。

截图清单的 `theme` 字段是请求给模拟器的外观。页面自身的 `nativeSystemTheme` 字段在本次采集中没有提供，不能把缺失字段解释为主题适配通过。实际配色应以图片为准。

## 数据如何理解

- 主行程使用应用自带的东京与濑户内示例旅程。页面有“模拟预览”提示；载具位置和行程时间不代表用户的实时位置或真实运营状态。
- 旅记最小面板显示 `ALL-TIME FLIGHTY PASSPORT`。本次未把演示路段标记完成，因此统计显示 0；这不等同于数据加载失败，也不能验证真实历史行程统计。
- 机场页展示目录、代码、坐标和收藏入口。没有把目录数据当作实时机场运行状态。
- 真实时间编辑仅展示表单，没有保存新计划、授权 GPS 或验证到达自动识别。
- 社区中可见的示例内容不代表已连通真实社区后端；只打开发布弹窗，没有发布内容。
- 页面按顺序采集，模拟播放和地图状态没有冻结。不同截图可能显示不同路段或地图位置；这不是相同时间点的对照实验。

## 不包含的验证

本次覆盖当前主要页面及指定展开/收起/表单状态，不穷举每个滚动位置、每个输入组合或外部服务返回结果。不包含原生键盘、权限/分享/文件选择系统界面、真实设备安装、连续拖动手势、后台定位、推送、真实航班/列车查询结果或社区提交验收。无当前导航入口的旧版组件列在截图目录的覆盖边界中。

现有 IPA 仍是 `51173f1` 的旧构建；本次原始截图对应清单中的新模拟器编译提交。两者不可混称为同一个二进制版本。
