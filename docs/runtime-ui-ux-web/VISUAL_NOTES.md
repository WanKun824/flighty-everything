# UI / UX 本地网页验收记录

验收日期：2026-10-18。对应方案：[UI-UX-改进计划](../UI-UX-改进计划.md)。

> **本记录仅为 Windows Chrome 网页验收，不是 iOS 模拟器/真机验收。**
> 本轮未生成 IPA / APK、未触发 GitHub Actions 或 iOS 截图工作流。`native:build` 只构建 Capacitor 使用的 Web 资源。

## 本轮落地

- 新增 `app/ios-tokens.css` 和 `app/ios-ui.css`，统一主要界面的字体、语义色、材质、按钮反馈、分组背景与减弱动态效果规则；Web/native 共同加载。
- 清理四个确认无运行时引用的旧页面实现；保留兼容存储键，未迁移或清空用户已有数据。
- 主底栏为「行程 / 同行 / 旅迹 / 社区」加独立搜索；个人资料由头像进入。社区列表、详情和发布均可在主应用中访问，旧社区地址仍兼容。
- 添加行程保留一个入口。航班号、航线和日历工具作为添加流程中的次级页面；返回时保留日期、起终点和已导入路段。
- 主要可拖动面板共用三档配置和手势；浮动控件按实际地图容器、安全区和面板高度计算位置，空间不足或面板升高时隐藏。大档隐藏底栏，滚动区域预留底栏空间。
- 次级页面打开时，主面板隐藏且 `inert`。共享 `SheetHeader` 提供返回、关闭、分享；关闭按钮为 30px 可见圆底、44px 点击区。
- 路段详情使用大号等宽时间、进度条和分组内容；行程列表移除图标下的额外模式文字，模式放在行程标题旁。
- 旅迹使用中性分组卡片，去除旧紫色地图配色；无已完成行程时展示明确空状态。机场搜索常驻列表顶部。
- 路段和整趟删除先确认，再提供撤销。整趟撤销恢复原顺序和活动旅程；路段撤销保留期间产生的新编辑和新路段。
- 主动清除本地数据需要确认；取消不改变数据，确认才清除行程、资料、同行、收藏及规划草稿。
- 接入官方 ActionSheet / Dialog / Share / Keyboard 插件，补充触觉反馈。iOS 设置 `KeyboardResize.None`，由一个视口 hook 合并原生与浏览器键盘高度，避免重复扣减。
- 社区发布使用浏览器顶层模态表单与 0.2 遮罩，支持焦点循环、Escape 和原生返回桥接；表单打开时隐藏原生底栏/地图浮动控件。
- 同行仍是原项目的**本地演示**，已明确标注，不再承诺真实用户共享。
- 地图失败不再只显示永久加载提示，提供重试且不改动已保存行程。推入的表单页面采用不透明背景，避免底层地图文字透出。

## 尚未完成，不能勾选整体验收

1. **样式整合仍是过渡状态。** 核心界面使用语义令牌，但令牌文件仍保留约 420 个历史调色板值；旧 CSS 命名空间和多层覆盖没有全部清除。不能把“裸颜色集中到一个文件”当作“已收敛为约 15 个语义色”。11 档字体已定义，旧组件也并未全部改成这 11 档。
2. **Lint 尚未全绿。** 对对应 HEAD 源码检查可复现现有规则问题：`FlightGlobe.tsx`、`JourneyComposer.tsx` 的 effect 同步状态/依赖和 `Date.now()`；未改动的 `Vehicle3D.tsx`、`useRealJourney.ts` 的 render ref/effect 状态。没有禁用规则或伪报通过。本轮移除了新增未使用导入，并修复了新焦点 hook、返回 hook 及机场加载状态问题。
3. **原生验收未执行。** Windows 无法运行 Xcode/iOS 模拟器；本轮未触发远程工作流。尚无本轮真实 iOS 截图，不能关闭阶段 2 / 3 / 5 的原生截图门槛。
4. **尚非浅色 32 页 + 深色全量走查。** 当前网页用例覆盖 13 种截图状态及 11 条交互流程；真实地图、所有航班查询分支、天气/图层完整页面、原生分享/震动、系统字号/VoiceOver、iOS 26 玻璃效果仍需真实环境走查。
5. **可访问性只完成部分验证。** 核心语义文字色/填充按钮对比度通过 4.5:1 测试；不能据此断言旧组件、地图标注和全部控件均已达标。
6. **依赖安全报告仍需独立处理。** 本次安装时 npm 报告 36 项漏洞（1 low、9 moderate、24 high、2 critical），未自动进行可能破坏兼容性的升级。

## 复现

```sh
npm ci
npm test
npx tsc --noEmit -p tsconfig.json
npm run native:build
npx playwright test
npx playwright show-report build/ui-acceptance-report
```

浏览器配置见 `playwright.config.mjs`：默认使用本机 Chrome，可通过 `PLAYWRIGHT_CHROME_PATH` 指定路径。测试使用隔离浏览器配置，不访问或改写用户日常浏览器的数据。
