# 面板与旅程交互校准

本轮以用户给出的 Flighty 行程、机场、搜索、Passport 截图为视觉目标，保留项目的飞机、列车、汽车、轮船功能。不是对 iOS 真机验收或实时运输数据覆盖的声明。

## 面板规则

- 行程与同行默认紧凑，旅记默认展开。三档约为 32%、57%、93%；小屏使用至少 256 CSS px，原生安全区另计。
- Dock 固定在底部安全区上方，不参与列表滚动。路段详情与机场覆盖页隐藏主 Dock，避免叠放两套操作。
- 行程总览点击仅展开/收起路段。路段第一次点击选中地图，再次点击或点箭头打开详情。
- 主面板、路段详情、机场和旅程编辑均不需要横条：从标题、留白或正文开始纵向拖动。
- 向上先展开，最高档后滚动正文；向下先把正文滚回顶部，再收起面板。最小档不会继续下拉关闭；关闭/返回控件保留。
- 输入框、原生选择器和 Dock 操作不触发面板拖动；横向标签保持横向滚动。明显拖动之后抑制误点击。
- 每个主标签分别保留高度与滚动位置。正文在固定标题下方裁切，不会穿过标题。
- 路段详情继承打开前面板高度，最低档保留固定摘要；阅读覆盖页期间，回放结束不会自动替换正在阅读的路段。
- 浅色与深色使用同一套布局尺寸。信息层保持较实的材质保证可读，Dock 与圆形工具使用玻璃材质。尊重减少动态效果、减少透明度设置。

## 旅程、路段与旅记

1. 一趟旅程包含有序路段；旅程内“添加路段”默认归入该旅程。
2. 全局搜索不擅自追加到当前旅程，必须明确选择已有旅程或新建旅程，并选定起点。
3. 路线不连续时提示缺少接驳，但不自动拆成另一趟旅程。
4. 已暂存数与待确认路段数分开显示；退出未保存规划提供继续编辑、保存草稿、放弃草稿。
5. 地图回放只更新播放选中项，不改变计划路段的实际完成状态。
6. 旅记自动派生自已完成路段；无需另点“保存到旅记”。删除、撤销完成会重新计算统计。
7. 年份按本地实际/计划出发日期归类，不使用保存年份。缺少年份保留在“日期待补充”，不猜年份；记录按旅行日期倒序排列。
8. 删除路段提供撤销；删除整趟旅程先确认影响。旅程编辑移除了未使用的主页名称字段。

## 机场数据边界

机场名称、代码、坐标从完整机场目录查询。点选未内置的机场，不再错误回退为香港机场。

目前没有接入可信实时机场运行指标，因此移除了示例准点率、延误率、正常/异常结论及无功能报告按钮。地图上的未知运行状态使用中性色，不把“无数据”画成“正常”。

## 本轮验证

- TypeScript 类型检查、Web 生产构建、原生 Web 资源构建。
- 自动测试覆盖手势消费顺序/硬边界、点击抑制、旅程归属/去重、回放不改完成状态、完成统计/年份/日期排序、独立标签状态、机场目录查找及无错误回退等。
- 在内嵌浏览器的 390×844 与 375×667 视口验证深浅色与面板占比，无横向页面溢出。375×667 紧凑面板约 256 px，390×844 约 270 px。
- 行程总览折叠测试：中档约 481 px 保持不变，路段从 5 行变为 1 行，没有打开详情。
- 在详情正文上拖动可以收起，最小档继续下拖不关闭；拖动没有误打开路段。
- 旅记滚动约 299 px 后切换同行再返回，恢复到相同位置。
- 全局添加实际创建独立临时旅程：未完成时旅记不增加；手动完成后由 5 段变为 6 段；确认删除临时旅程后恢复为 5 段。测试旅程已清理，原有旅程保留。
- KEF 搜索、详情代码 BIKF/KEF、坐标与收藏开关核对；收藏开关测试后恢复原值。

尚未在本轮执行 iPhone 真机、iOS VoiceOver、系统键盘、原生 Liquid Glass 以及安装包的端到端测试。浏览器尺寸验证不能替代这些验收；本轮没有生成新的 IPA。
