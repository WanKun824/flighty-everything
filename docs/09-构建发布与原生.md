# 原生构建与发布机制

最新操作以 [开发与按需构建](开发与打包说明.md) 为准。仓库只保留最新源码，没有安装包、旧发布或截图档案。

当前 iOS / Android 将 `native-shell/` 中生成的 Web 资源通过 Capacitor 内嵌，并提供平台桥接；不是仅打开线上 URL 的容器。前端改变后需要重新 build、sync 和平台构建，不会自动更新已经安装的旧应用。

- `ci.yml`：main / PR 的 lint 与代码构建测试，不上传安装包。
- `ios.yml`：仅手动触发，先生成内嵌资源并同步，再构建设备 IPA；默认跳过模拟器阶段。
- `android.yml`：仅手动触发，先构建前端并同步，再由 Gradle 生成 APK。
- `web-package.yml`：仅手动触发，按明确需求生成 Web、源码或文档包。
- Codemagic 配置仅作为可选构建源文件保留，没有配置自动 push 触发器。

所有输出都属于可再生文件，不提交回仓库。iOS 签名、云账号、D1 与目标部署环境必须由使用者配置；源码可公开查看不代表已经完成发布或真机验收。
