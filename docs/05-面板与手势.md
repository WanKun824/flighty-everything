# 5 · 面板与手势

`app/JourneyPanel.tsx`（324 行）是面板容器，`app/panelGeometry.ts`（131 行）是所有手势的
纯函数（能被 `tests/panel-geometry.test.mjs` 直接测）。**同一套 DOM，桌面是浮窗、窄屏是
带停位的 sheet**，由媒体查询切换样式（globals.css 210 行、564 行）。

## 5.1 坐标约定与常量

`panelGeometry.ts`：

```ts
TOP_LIMIT 82    // 顶栏保留带下沿，与 globals.css 的 .journey-panel { top: 82px } 必须一致
EDGE 14         // 面板离舞台边缘的最小距离
SNAP 24         // 松手离边缘 24px 内就吸附贴边
MIN_W 320 / MAX_W 560 / MIN_H 260 / DEFAULT_W 378
stageFromViewport = (w - 122, h - 24)   // 122 = 桌面导航 86 + 间隙 12×3，24 = app-shell padding
```

`clampBox` / `defaultBox` / `dockX` / `snapX`：把盒子夹进舞台、给默认位、贴边吸附。
`detentHeight`（窄屏停位）：small **216**、medium `.52·h`、large `min(.88h, h−148)`。

## 5.2 拖拽与缩放（桌面）

`JourneyPanel` 里三个手势：

- **标题栏整条可拖**（`.panel-chrome`，`cursor: grab`，`touch-action: none`）。`DRAG_SLOP = 4`：
  按下先不认，移动超过 4px 才进拖态 —— 不然单击标题栏也会触发一次 setState。
- **三个缩放把手**（`.panel-resize-e / -s / -se`），是 `role="separator"` + `tabIndex` 的
  ARIA window-splitter（方向键也能调）。CSS 平时不画把手，鼠标靠近才浮出细线
  （globals.css 236–240 行）。
- 拖/缩放是**逐帧只写 `el.style`，松手才 setState**（存 localStorage）：过程中不碰 React。
- 吸附贴边时套一圈主色框（`data-snapped`）；手势中把毛玻璃降一档
  （`data-interacting`，42px 的模糊每帧重算会掉帧，Apple 在交互中也是这么降材质的）。
- 双击标题栏回默认位，**Alt+双击存默认位**（WAAPI 弹一下做反馈）。
- 隐藏：桌面整块滑出左侧、窄屏落到屏幕下方（`data-hidden` 的 transform），DOM 留着让动画
  有东西可动。

## 5.3 窄屏 sheet

- 三个停位（`detentHeight`），拖动中按位移落位、快速一甩按投影落位（`projectHeight`，
  `PROJECTION_MS 250`）。
- `rubberBand`（阻尼 `.35`、封顶 40px）：拖过最高停位有阻尼。
- `shouldDismiss`（`DISMISS_SLACK 64`）：下拉超过最低停位 64px 才关闭，停在最低停位不关；
  `dismissHint`（最低 `.72`）：临近关闭时给淡出提示，正常高度不淡。
- 高度由 JS 写成内联样式（`--sheet-h` 写在 `documentElement`，地图版权条和镜头让位都读它，
  见文档 2 §2.10）；CSS 里的 `52dvh` 只是 JS 接手前那一帧的默认值（正好等于 medium 停位）。
- **不再有 `.collapsed` 第二态**：收到最低停位时列表被 overflow 自然切掉 —— 少一套状态
  就少一处会对不上的地方（globals.css 560–563 行注释）。

## 5.4 持久化与可达性约束

- `STORE_KEY = "manyou:journey-panel"`（位置与尺寸）、`HOME_KEY = "manyou:journey-panel-home"`
  （Alt+双击存的默认位）。
- `inert={hidden}`：面板隐藏时整块对键盘/读屏不可达，但视觉还在（动画）。
- 两个 `jsx-a11y/no-noninteractive-element-interactions` 局部豁免：缩放把手是
  ARIA window-splitter 模式，交互合法但规则认不出来。
- **类名必须是静态字面量**：`tests/rendered-html.test.mjs` 的类名漂移检查只认 JSX 里的
  静态字符串类名，拼出来的条件类名会直接漏检。所以状态一律用 `data-*` 属性
  （`data-hidden` / `data-interacting` / `data-snapped`）+ 静态字面量类名的组合，
  CSS 用属性选择器挂样式。**新状态照这个模式加，别在 className 里拼**。
- `container-type: inline-size` + `@container (max-width: 340px)`：内容响应「面板宽度」
  而不是视口宽度 —— 不然拖窄了内容不会让，「自由缩放」就只是改了个盒子大小
  （globals.css 208–209 行、246–248 行）。

## 5.5 面板结构（内容由 ExploreScreen 填充）

```text
.panel-chrome     标题条（可拖）＋ .panel-grabber 拉杆 ＋ .panel-close 关闭钮
.panel-head       LIVE JOURNEY 眉标 · 标题 · 统计行 · .panel-source 几何来源行 · 编辑按钮
.clock-sync-card  预览动画 / 真实时间 切换 + 时间段输入
.panel-player     播放器：播放/暂停 · 段名 · 上一段/下一段 · 进度条 · 倍速滑块
.panel-tabs       行程 / 站点 / 载具 分段
.panel-body       对应分段内容
```

`container-type` 让内容按面板实际宽度排版；窄屏隐藏 `.leg-step` 后，换段靠
点站、点线、拖进度条（globals.css 571–573 行）。
