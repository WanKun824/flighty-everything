# 开发、配置与按需构建

当前以公开仓库 `WanKun824/flighty-everything` 的 `main` 为准。只维护最新源码，旧版本发布、截图/GIF 和所有交付包已清理。

## 环境与运行

Node.js 22.13+、npm、Git；浏览器回归使用本机 Chrome。Python 工具需要 Python 3.10+。iOS 构建必须在 Mac/Xcode 上进行。

```sh
npm ci
npm run dev
```

验证命令：

```sh
npm test
npx tsc --noEmit -p tsconfig.json
npx playwright test
npm run lint
```

默认回归只检查交互，不输出截图、录屏或 trace。浏览器使用隔离存储并阻断部分外部服务，不能证明线上数据或原生控件全部合格。既有 lint 问题仍须修复。

## 配置与数据

- React 19 / TypeScript / Vite（vinext）+ Capacitor 8；Web 使用 Workers / D1，不是任意静态站点直接部署。
- Web 的公开 Mapbox token 配置参考 `.env.example`。原生 `vite.native.config.ts` 当前将环境 token 设为空，使用 `app/mapboxConfig.ts` 中的公开备用 token；仅修改 `.env.local` 不会替换原生 token。
- 地图 Mapbox；天气 Open-Meteo；雷达 RainViewer；机场基础目录 OurAirports。机场地点并非实时运营信息。
- 本机行程、资料、收藏与草稿不自动跨设备备份。清除或卸载可能丢失数据。
- `app/demoJourneys.ts` 中三组八段均为虚构演示样例；仅新存储首次启动使用，已有有效存储不自动合并演示数据。
- 同行是本地演示；原生社区与 Web D1 社区不等同于完成真实同步。
- 当前没有向线上环境自动部署，也没有提供签名证书、用户数据或生产数据库。

## 按需构建，不自动发布

以下命令会在本机生成资源；仓库不保存这些输出。本次清理没有执行设备打包，也不提供下载包。

```sh
npm run native:build       # 仅生成 Capacitor 内嵌 Web 资源
npm run ios:sync           # Mac 上同步后使用 Xcode 打开工程
npx cap open ios
npm run android:debug     # Windows：同步前端并由 Gradle 构建 APK
```

Mac/Linux 的 Android 流程：`npm run native:build` → `npx cap sync android` → `cd android && chmod +x gradlew && ./gradlew assembleDebug`。

iOS 应用 ID 为 `com.wankun824.flightyeverything`。设备 IPA 与模拟器 `.app` 不能互相替代；未签名 IPA 必须自行签名后才能在标准设备安装。删除生成资源后应重新 build → sync，不要依赖历史 `public/` 副本。

GitHub 的 `ios.yml`、`android.yml`、`web-package.yml` **仅支持显式 `workflow_dispatch`**。普通 main push 或版本 tag 不会触发打包；不要在无需安装包时启动这些工作流。iOS 默认跳过模拟器阶段。当前公开仓库的 Releases、版本标签、旧打包分支与构建 artifacts 均不作为交付存储使用。

若将来明确需要源码 ZIP，可手动执行 `python scripts/package-source.py`。工具排除凭据、依赖、缓存和生成包，并保留 `build/sites-vite-plugin.ts` 等必需源码；它不会自动上传 Release。当前没有保留任何此类 ZIP。
