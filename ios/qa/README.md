# 原生 QA 源代码

此目录只保留测试与页面目标工具的源代码，不包含截图、GIF、设备包或模拟器应用。远程逐页截图工作流和已有图册已删除，不再自动采集或上传。

- `capture-pages.py --list` 输出 32 个当前页面目标，浏览器导航回归仅使用该列表验证可达性。
- 原生交互测试、布局校验及页面导航桥接用于开发者明确选择的 QA，不是已完成的设备验收证明。
- 原生命令桥仅在模拟器编译目标中存在，还需显式开启 `FLY_SCREENSHOT_SESSION=1`；正常应用不会启用。
- Python 文档/图像工具仍是可选源代码，不由日常 CI 触发。只有今后明确需要原生采集时才使用，当前没有任何可下载的历史图像产物。

普通代码回归运行 `npx playwright test`，默认不截图、不录屏、不保存 trace。iOS 构建前需在 Mac/Xcode 上重新生成前端并 `cap sync ios`；本次清理没有运行模拟器或生成设备包。
